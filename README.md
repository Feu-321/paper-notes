# paper-notes

论文阅读记录。每周一篇，每篇一页。

## 规则

- 一篇论文 = 一个文件，放在 `notes/` 下，文件名格式 `YYYY-MM-简称.md`
- 每篇笔记按同一个骨架写，不要自由发挥格式——格式统一了才能比较
- **不做完不提交**：笔记里必须有"我接下来想试的是 ___"，哪怕只是猜测
- 每 2–3 周检查一次：这段时间我读了什么？我在哪一类问题上停留得最久？

## 为什么记这个

这是训练记录。两三年后回来看，它会告诉你三件事：
你的注意力实际流向了哪里、你的判断力有没有变准、以及你从哪一天开始不再是新手。

## 骨架

每篇笔记按这个顺序写：

1. 一句话：它解决了什么问题
2. 它主张什么
3. 它怎么证明（基线 / 指标 / 消融）
4. 它的条件与边界（作者自己承认的前提）
5. 它没说什么
6. 我的判断：哪里可信，哪里可疑
7. 我接下来想试的是 ___
